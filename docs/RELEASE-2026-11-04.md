## Deployment procedure

Wrangler is pinned in package-lock.json. Authenticate through Cloudflare's normal authorization flow; never put tokens in source or chat. With authentication available:

```sh
npm ci
python scripts/prepare_release.py
npx wrangler versions upload --message "Describe reviewed changes"
```

Inspect the returned preview URL and compare its HTML/PDF hashes before promoting the exact returned version:

```sh
npx wrangler versions deploy VERSION_ID@100 --message "Approved release" --yes
```

Upload source to a development branch, then merge/fast-forward the approved state to main. GitHub is canonical, but pushes currently do not automatically deploy the Worker. `output/site` is the only asset directory. Fetch production HTML/PDF after release and compare to `output/release-checks.json`.

Python dependencies are listed in scripts/requirements-pdf.txt. Render and review both PDF pages after future layout/content changes.
